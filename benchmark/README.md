# Benchmark artifacts

This directory is empty until `scripts/select_benchmark_samples.py` is run
against the real CarDD annotation files. Expected order of artifacts
(per TZ sections 8-9):

1. `dev_examples.txt` / `dev_examples.json` — 18 image IDs from CarDD's
   validation split, 3 per damage class. Generated by the sampling script.
2. `test_examples.txt` / `test_examples.json` — 24 image IDs from CarDD's
   test split, 4 per damage class. Generated by the sampling script.
   **Commit both example lists before any labeling or prompt tuning
   starts** — they must be fixed in advance.
3. `ground_truth_dev.json` — manually labeled part/severity/action for each
   dev image, first annotator + independent second-annotator check
   (TZ section 9). Not yet created.
4. `ground_truth_test.json` — same, for the test set. Not yet created.
5. `target_thresholds.json` — recall/precision/F1/severity-accuracy/Brier
   score thresholds, fixed *after* dev-set experiments and *before* the
   test set is run (TZ section 11). Not yet created.
6. `test_results.json` + benchmark report — output of the (not yet
   implemented) benchmark runner against the frozen test set.

Nothing in this directory should be regenerated with a different random
seed or a different image list once ground truth labeling has begun.
