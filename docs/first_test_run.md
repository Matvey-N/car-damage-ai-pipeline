# Первый прогон тестов

> Исторический отчёт первой вехи (тогда ещё на заглушке и с классами CarDD). Актуальное состояние тестов — в README, раздел «Статус».

Данные: только синтетические (доступ к CarDD ещё не получен). Модель: заглушка (API не вызывался).

## Java — ядро pipeline (31 тест)

Окружение: OpenJDK 21, компиляция с `--release 17`, JUnit 5.10.

```
[        31 tests found           ]
[        31 tests successful      ]
[         0 tests failed          ]
```

Проверяется: парсинг ответа (JSON, JSON в markdown-блоке, проза, битый JSON, пустой ответ),
проверка формата (enum, диапазоны, отсутствующие поля, рамка: пиксели вместо долей, выход за
границы, неверная длина), retry (невалидный ответ → повтор, сбой вызова → повтор, нарушения
передаются в повторный промпт, рост паузы), fallback (корректный JSON со status=error после
3 попыток), «повреждений нет» ≠ ошибка, объединение серии фото.

## Python — выборка и оценка (20 тестов)

```
Ran 20 tests in 0.193s

OK
```

Проверяется: IoU, правило «одно предсказание — одно эталонное повреждение» (дубль → FP,
одно предсказание не закрывает два эталона, значение ровно 0.5 сопоставляется, 0.49 — нет),
ошибка pipeline → все эталоны FN, серьёзность и уверенность только по парам;
выборка: 18 + 24, по 3/4 на класс, без повторов, одинаковый seed → одинаковая выборка.
